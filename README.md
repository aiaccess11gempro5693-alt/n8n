# n8n — автоматическая фабрика контента

Проект: n8n-пайплайн, который по теме сам генерирует сценарий, озвучку и картинки для короткого видео.

## Кто за что отвечает (важно, не путать роли)

- **Claude Code (я, в чате)** — сложная творческая часть: сценарий (текст озвучки) и черновые описания сцен.
- **Gemini** — дешёвая механическая часть: доработка черновых описаний в детальные промпты для рендера + проверка качества готовых картинок. Это "оркестрация", а не рендер.
- **Nano Banana** (модель генерации изображений Gemini) — сам рендер картинки по промпту. Отдельная роль от "Gemini-оркестрации" выше, хоть провайдер один и тот же.
- **ElevenLabs** — озвучка текста.

## Полный план (все этапы)

1. **Сценарий + черновые описания сцен** — Claude Code. ✅ есть в MVP
2. **Доработка промптов + проверка качества картинок** — Gemini. ✅ есть в MVP
3. **Рендер картинок** — Nano Banana. ✅ есть в MVP
4. **Озвучка** — ElevenLabs. ✅ есть в MVP
5. **Аватар** — Heygen. 🔜 следующий шаг после MVP
6. **Монтаж видео** — субтитры, склейка картинок/видео, вставка аудио. 🔜
7. **Публикация** — VK, Instagram, сайт + хранилище контента. 🔜
