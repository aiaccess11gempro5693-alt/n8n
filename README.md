# n8n — воркеры для автоматической фабрики контента

Проект: n8n хостит несколько независимых "воркеров" (Webhook-адресов), которые по отдельности вызывает Claude Code, чтобы собрать короткое видео — сценарий, озвучка, картинки, аватар, монтаж.

## Архитектура: n8n — это НЕ один автопайплайн

Вся "умная" оркестрация — диалог с человеком, решения ok/не-ок, финальный монтаж видео — происходит **снаружи n8n**, в чате с Claude Code. n8n только выполняет конкретные механические задачи по запросу и возвращает результат. Это сознательное решение: n8n тут — инфраструктура, а не мозг процесса.

## Кто за что отвечает (важно, не путать роли)

- **Claude Code** — пишет сценарий, раздаёт задачи ElevenLabs/Heygen/Nano Banana, спрашивает у человека ok/не-ок по каждому куску, при "не ок" отправляет конкретный элемент на переделку, в конце сам делает монтаж видео и субтитры.
- **Gemini** — дешёвая механическая часть: дорабатывает описание сцены в детальный промпт для рендера + проверяет качество готовой картинки. Это "оркестрация промптов", а не сам рендер.
- **Nano Banana** (модель изображений Gemini) — сам рендер картинки по промпту. Отдельная роль от Gemini-оркестрации выше, хоть провайдер один и тот же.
- **ElevenLabs** — озвучка текста.
- **Heygen** — аватар. Важная часть результата, а не просто "слой поверх".

## 4 воркера в n8n

| Адрес | Метод | Что делает |
|---|---|---|
| `/tts` | POST | Озвучка текста (ElevenLabs) |
| `/image` | POST | Промпт (Gemini) → картинка (Nano Banana) → проверка качества (Gemini) |
| `/avatar-start` | POST | Запускает генерацию аватара в Heygen, сразу возвращает `video_id` |
| `/avatar-status` | GET | Проверяет по `video_id`, готово ли видео с аватаром |

## Полный план (все этапы)

1. **Сценарий + описания сцен** — Claude Code.
2. **Доработка промптов + проверка качества картинок** — Gemini. ✅ воркер `/image` готов
3. **Рендер картинок** — Nano Banana. ✅ входит в `/image`
4. **Озвучка** — ElevenLabs. ✅ воркер `/tts` готов
5. **Аватар** — Heygen. ✅ воркеры `/avatar-start` + `/avatar-status` готовы
6. **Монтаж видео** — субтитры, склейка картинок/видео, вставка аудио. 🔜 делает Claude Code сам, без n8n
7. **Публикация** — VK, Instagram, сайт + хранилище контента. 🔜 сознательно отложено
