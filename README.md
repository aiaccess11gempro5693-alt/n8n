# n8n — автоматическая фабрика контента

Проект: n8n-пайплайн, который по теме сам генерирует сценарий, озвучку и картинки для короткого видео.

## Полный план (все этапы)

1. **Сценарий + промпты** — пишет Claude Code (этот чат), без отдельного API.
2. **Озвучка** — ElevenLabs. ✅ есть в MVP
3. **Картинки** — Google Gemini / "Nano Banana". ✅ есть в MVP
4. **Аватар** — Heygen. 🔜 следующий шаг после MVP
5. **Монтаж видео** — субтитры, склейка картинок/видео, вставка аудио. 🔜
6. **Проверка качества** — оркестратор на базе Gemini. 🔜
7. **Публикация** — VK, Instagram, сайт + хранилище контента. 🔜

## Файлы

- `docs/SETUP.md` — пошаговая инструкция: какие аккаунты/API-ключи нужны и как всё настроить.
- `workflows/mvp-content-pipeline.json` — готовый воркфлоу для импорта в n8n (MVP: сценарий → озвучка → картинки, шаги 1–3 выше).
- `CLAUDE.md` — правила работы над проектом для Claude (ветвление чатов и т.п.).
