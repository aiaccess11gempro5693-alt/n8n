# n8n — воркеры для автоматического конвейера обучающих видеороликов

Проект: полностью автоматизированный конвейер создания обучающих видеороликов (ТЗ от 31.07.2026 — см. `CLAUDE.md`). n8n хостит несколько независимых "воркеров" (Webhook-адресов), которые по отдельности вызывает Claude Code, чтобы собрать видео: сценарий → подложки/инфографика/изображения → озвучка → аватар → проверка качества → монтаж с субтитрами.

**Сейчас в репозитории — рабочий MVP** (упрощённая версия, 4 воркера ниже). Полное ТЗ значительно шире — оно целиком приведено и разобрано по пунктам в `CLAUDE.md`, там же — таблица "что уже сделано / что нет" и список открытых вопросов, которые нужно закрыть перед реализацией полной версии (например: где взять согласованный стиль/референсы/шрифты/переходы, как совместить "без ручного участия" из ТЗ с ранее оговорённым ok/не-ок с человеком).

## Архитектура: n8n — это НЕ один автопайплайн

Вся "умная" оркестрация происходит **снаружи n8n**, в чате с Claude Code. n8n только выполняет конкретные механические задачи по запросу и возвращает результат. Это сознательное решение: n8n тут — инфраструктура, а не мозг процесса.

## Кто за что отвечает (важно, не путать роли)

- **Claude Code** — пишет сценарий (в перспективе — по полному ТЗ: разбивка на сцены, текст диктора, текст на экране, промпты для картинок/инфографики, разметка где аватар/где инфографика), раздаёт задачи ElevenLabs/Heygen/Nano Banana, в конце сам делает монтаж, текст на экране и караоке-субтитры.
- **Gemini** — дешёвая механическая часть: дорабатывает промпты + проверяет качество (сейчас — картинок; по ТЗ — также озвучки и аватара, с решением о перегенерации).
- **Nano Banana** (модель изображений Gemini) — сам рендер (подложки, инфографика, изображения) по промпту.
- **ElevenLabs** — озвучка текста (по ТЗ — с SSML/ударениями/паузами для естественности).
- **Heygen** — аватар. Важная часть результата, а не просто "слой поверх".

## MVP: 4 воркера в n8n (уже готово)

| Адрес | Метод | Что делает |
|---|---|---|
| `/tts` | POST | Озвучка текста (ElevenLabs) |
| `/image` | POST | Промпт (Gemini) → картинка (Nano Banana) → проверка качества (Gemini) |
| `/avatar-start` | POST | Запускает генерацию аватара в Heygen, сразу возвращает `video_id` |
| `/avatar-status` | GET | Проверяет по `video_id`, готово ли видео с аватаром |

Отличия MVP от полного ТЗ: один универсальный тип картинки вместо подложка/инфографика/изображение по отдельности; без SSML; проверка качества есть только для картинок и не запускает автоматическую перегенерацию (просто возвращает вердикт).

## Полный план по ТЗ (этапы конвейера)

1. Генерация сценария (сцены, текст диктора, текст на экране, структура инфографики, описания изображений, промпты).
2. Генерация промптов.
3. Генерация подложек (Nano Banana, фиксированный согласованный стиль).
4. Генерация инфографики (Nano Banana, согласованные стиль/дизайн/референсы/цвета/композиция).
5. Генерация изображений. ✅ базовая версия есть в `/image`
6. Генерация аватара (Heygen). ✅ есть в `/avatar-start` + `/avatar-status`
7. Генерация озвучки (ElevenLabs, с SSML). ✅ базовая версия (без SSML) есть в `/tts`
8. Проверка озвучки (Gemini) + авто-перегенерация.
9. Проверка изображений (Gemini) + авто-перегенерация. ✅ проверка есть в `/image`, авто-перегенерации пока нет
10. Проверка аватара (Gemini) + авто-перегенерация.
11. Повторная генерация при обнаружении ошибок (общий механизм ретраев).
12. Автоматический монтаж (3 типа сцен: полноэкранный аватар / инфографика+PIP-аватар / иллюстрация+PIP-аватар).
13. Добавление текста на экране (шрифт/цвет/анимации при монтаже).
14. Добавление караоке-субтитров (белая плашка, чёрный текст, синхро по словам).
15. Финальный экспорт видео.
16. Публикация (VK, Instagram, сайт) + хранилище. — сознательно отложено, вне текущего скоупа.

Полный текст ТЗ, статус по каждому пункту и открытые вопросы — в `CLAUDE.md`.
