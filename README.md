# n8n — автоматическая фабрика контента

Проект: n8n-пайплайн, который по теме сам генерирует сценарий, озвучку и картинки для короткого видео (а в перспективе — аватар, монтаж, проверку качества и публикацию в соцсети).

- `docs/SETUP.md` — пошаговая инструкция: какие аккаунты/API-ключи нужны и как всё настроить.
- `workflows/mvp-content-pipeline.json` — готовый воркфлоу для импорта в n8n (MVP: тема → сценарий → озвучка → картинки).
- `CLAUDE.md` — правила работы над проектом для Claude (ветвление чатов и т.п.).
