# Разбор сценария для тестового видео — "Сценарий 4 (иммунитет)"

Это **не дизайн-система** (Шаг 0 из `CLAUDE.md` — отдельный, всё ещё не пройденный процесс). Это разбор конкретного сценария от Олега — «Сценарий 4. Когда покупатель говорит: "Для иммунитета что-нибудь"» — на сцены, чтобы попробовать собрать по нему тестовое видео (Шаг 1 из ТЗ: сценарий → разбивка на сцены → промпты).

Визуальные решения ниже (палитра, стиль иконок и т.п.) — это **черновые решения только для этого теста**, чтобы было из чего рендерить картинки прямо сейчас. Они не утверждены как постоянная дизайн-система — если тест понравится, можно будет уже осознанно зафиксировать что-то похожее как Шаг 0 на будущее; если нет — переделать без потерь для остального проекта.

## Визуальные решения, использованные для этого теста (не финальная дизайн-система)

- **Палитра:** тёплый белый фон (`#F7F9FB`), бирюзовый акцент (`#2A7F82`), коралловый акцент (`#F2836B`), текст тёмно-серый (`#2B2F33`).
- **Инфографика:** плоские карточки со скруглёнными углами, outline-иконки, без текста внутри (текст накладывается при монтаже отдельно).
- **Переходы:** спокойные — fade/масштабирование, без резких эффектов.

Взято просто как рабочая гипотеза, чтобы было что подставлять в промпты для теста — не результат отдельного обсуждения дизайна.
