# Предложение дизайн-системы (Шаг 0) — черновик на утверждение

Это черновое предложение от Claude Code (+ Gemini на подхвате для инфографики), сделанное на конкретном примере — "Сценарий 4. Когда покупатель говорит: «Для иммунитета что-нибудь»". Ничего из этого пока не зафиксировано как финальное — это база для правок. Как только утвердим — станет референсом для всех последующих роликов (Шаг 0 из `CLAUDE.md`).

## 1. Визуальный стиль (черновик, нужно утвердить/поправить)

Контекст — обучающее видео для аптечных сотрудников (фармацевтов). Предлагаю:

- **Тон:** профессиональный, но тёплый и не "корпоративно-холодный" — фармацевт как заботливый эксперт, не продавец.
- **Цветовая палитра:** мягкий медицинский, не агрессивный.
  - Основной фон: тёплый белый / светло-серый (`#F7F9FB`)
  - Акцент 1 (доверие/медицина): глубокий тёплый бирюзовый (`#2A7F82`)
  - Акцент 2 (забота/тепло): мягкий коралловый (`#F2836B`) — для выделения важных слов/иконок
  - Текст: тёмно-серый, не чёрный (`#2B2F33`) — мягче для глаз
- **Шрифт:** гуманистический sans-serif, хорошо читаемый в субтитрах и на инфографике (например, Inter / Manrope / PT Sans — финальный выбор зависит от того, что доступно в монтажном инструменте).
- **Аватар:** фармацевт в опрятной, но не "стерильной" форме (без агрессивно-белого халата), дружелюбная поза, речь — прямо в камеру, как разговор с коллегой.
- **Инфографика:** карточки со скруглёнными углами, мягкая тень, иконки в стиле "outline" (не заливка) в акцентных цветах, без фотореализма — плоский/полу-плоский стиль, чтобы не спорить визуально с аватаром.
- **Подложки:** однотонный/лёгкий градиентный фон в палитре выше, без отвлекающих текстур.

## 2. Переходы (черновик)

- Между "говорящая голова" ↔ "инфографика": мягкое масштабирование + fade (0.3–0.4 сек), без резких скачков.
- Появление элементов инфографики: последовательное появление карточек (стаггер 0.1–0.15 сек между карточками), лёгкое движение снизу вверх + fade-in.
- Аватар в PIP: не резкий "прыжок" в угол, а плавное уменьшение с панорамированием на 0.3 сек.
- Никаких резких/ярких эффектов (вспышки, быстрые zoom) — весь ролик спокойный, доверительный.

## 3. Правила качества (черновик критериев для авто-QA)

- **Озвучка:** без запинок/повторов, ударения на медицинских терминах верные (ОРВИ, иммуномодулятор, поливитаминный), темп — не быстрее разговорного.
- **Картинки/инфографика:** текст на инфографике (если Nano Banana что-то дорисует) не обязателен — весь текст добавляется при монтаже отдельно; изображение не должно противоречить смыслу сцены; никаких искажённых рук/лиц/лишних объектов.
- **Аватар:** синхронизация губ корректная, никаких артефактов на лице/руках, естественная мимика (не "застывшая").
- Порог для авто-перегенерации — если Gemini находит явный брак по любому из пунктов выше → перегенерация; если после 3 попыток брак остаётся → эскалация человеку (лимит ретраев, см. открытый вопрос №5 в `CLAUDE.md`).

- **Визуал:** говорящая голова, полный экран, тёплое приветствие
- **Промпт для изображения:** —
- **Промпт для инфографики:** —
- **Тип сцены:** Вариант 1 — полноэкранный аватар (16:9)

### Сцена 2 — Скрытая причина запроса

### Сцена 3 — Четыре возможных сценария
- **Текст диктора:** «Итак, покупатель говорит: "Дайте что-нибудь для иммунитета". Что он имеет в виду? Возможно, он болеет каждую осень и хочет это изменить. Возможно, только недавно перенёс ОРВИ и чувствует слабость. Возможно, просто устал и решил, что виноват "плохой иммунитет". А возможно, он уже принимает три разных БАДа и хочет добавить четвёртый.»
- **Текст на экране:** 4 карточки: «Частые простуды» / «После ОРВИ, слабость» / «Просто усталость» / «Уже принимает БАДы»
- **Визуал:** инфографика — 4 карточки-сценария с иконками
- **Промпт для изображения:** —

Например, если человек уже пьёт поливитаминный комплекс с высокой дозой витамина С, добавлять ещё один иммуномодулятор может быть излишним. А тому, кто только вышел из болезни, нужна восстановительная поддержка, а не стимуляция.»

- **Визуал:** инфографика — сравнение "было/нужно" (2 колонки: избыточная добавка vs восстановительная поддержка)
- **Промпт для изображения:** —

## 5. Что нужно от человека сейчас

Это черновик — нужно подтвердить или поправить:
1. Палитра/шрифт/тон аватара — подходит или другое видение?
2. Стиль инфографики (плоский/полу-плоский, скруглённые карточки) — ок?
3. Переходы — устраивает "спокойный" вариант без резких эффектов?
4. Разбивка сценария 4 на 8 сцен и типы сцен (когда аватар на весь экран / когда инфографика+PIP) — логично?

После утверждения — это станет зафиксированной дизайн-системой (см. Шаг 0 в `CLAUDE.md`), и дальше такие разборы сценариев можно будет генерировать уже автоматически.
