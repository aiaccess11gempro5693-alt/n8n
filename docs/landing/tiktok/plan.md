# TikTok «ИИАВАТАР»: план публикаций

Живой документ. Каждый новый готовый ролик (пост `docs/landing/insta/posts/NNN.json`) добавляется в очередь ниже, расписание продлевается на следующие дни. Подпись для TikTok — `python3 tools/tt_caption.py docs/landing/insta/posts/NNN.json`. Как ставить по расписанию — `setup.md`.

## Правила

- **Время (МСК).** Будни: 09:00 (дорога на работу), 13:00 (обед), 20:00 (вечер). Выходные: 11:00, 15:00, 20:00 — пики активности русскоязычной аудитории в коротких видео; между роликами не меньше 4 часов. Через 2–3 недели сверяемся со статистикой TikTok (часы активности подписчиков) и сдвигаем.
- **Частота.** 3 ролика в день (с 23.11 по решению пользователя; готовых роликов хватает почти на месяц), каждый день без пропусков. Больше 3 в день не ставим: ролики начинают отнимать показы друг у друга. Если через неделю у роликов падают просмотры в первые часы — возвращаемся к 2 в день.
- **Что первым.** Ролики, уже доказавшие себя в Instagram: рейтинг = просмотры + 30×репосты + 30×сохранения (репост и сохранение — главные сигналы и для TikTok). Первые дни — только самые сильные, чтобы алгоритм быстрее понял аудиторию.
- **Чередование.** В один день — две разные темы (дружба / отношения / уважение / уверенность / мотивация). Утром — короткое и мотивирующее, днём — списки и советы (их сохраняют), вечером — эмоциональное и «отправь тому, кто…» (их репостят).
- **Свежие ролики.** В TikTok — не раньше чем через сутки после Instagram.
- **Подпись.** Короче, чем в Instagram; призыв — в комментарии, а не «в директ» (комментарии поднимают ролик); 4–5 хэштегов, `#ииаватар` всегда. Делает `tools/tt_caption.py`.
- **Не публикуем в TikTok.** Тестовые ролики-примеры (001–007), сторис и карусели, первые версии роликов, у которых есть v2, ролики с датой в тексте, «Прайм Москвы».
