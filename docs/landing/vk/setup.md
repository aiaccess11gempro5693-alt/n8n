## 3. Разделы (Управление → Разделы)

Включить: **Клипы, Видео, Фото, Статьи, Ссылки, Товары (режим «Услуги»)**.
Выключить: Обсуждения, Мероприятия, Аудиозаписи, Документы.
**Главный блок:** Клипы. **Второстепенный:** Услуги.

## 4. Сообщения

- Управление → Сообщения: **включить**.
- Приветствие:

```
Здравствуйте! 👋 Расскажите, какое видео нужно: тема, длительность, для чего (реклама, обучение, соцсети). Посчитаем стоимость и пришлём примеры.
```

- На странице сообщества → кнопка действия → **«Написать сообщение»**.
- Ссылки (Управление → Ссылки): `https://iiavatar.ru` — «Сайт»; Telegram-бот — «Написать в Telegram».
- Комментарии: включить, фильтр мата и ссылок — включить.
