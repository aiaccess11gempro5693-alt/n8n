# Автозагрузка видео в ВК: что настроить (пошагово)

Цель: чтобы ролики и посты публиковались в сообщество «ИИАВАТАР | Видео с ИИ-ведущим»
автоматически, без ручной загрузки.

Почему сейчас не работает:
1. ВК при входе выдаёт приложению только доступ к профилю (имя, аватар) — без прав
   на стену, видео и сообщества. Это настраивается в кабинете VK ID (часть 1).
2. ВК привязывает ключ к серверу, который его получил. Вход и все запросы к ВК должны
   идти с одного сервера — с iiavatar.ru (часть 2 — это делает Claude в коде сайта).

---

## Часть 1. Кабинет VK ID — делаете вы (≈15 минут + ожидание модерации)

### Шаг 1. Откройте приложение

1. Зайдите на https://id.vk.com/business/go под тем аккаунтом ВК, который **владелец
   сообщества** ИИАВАТАР.
2. Слева «Мои приложения» (или «Приложения») → приложение с ID **54846620**.
   Если приложений несколько — нужное то, у которого этот ID.

### Шаг 2. Проверьте основные настройки

В разделе настроек приложения (обычно вкладка «Основное» / «Подключение»):

| Поле | Что должно стоять |
|---|---|
| Платформа | Web (веб-сайт) |
| Базовый домен | `iiavatar.ru` |
| Доверенный Redirect URL | `https://iiavatar.ru/api/vk` — ровно так: https, без слэша в конце, без пробелов |
| Статус приложения | включено / активно (если есть переключатель) |

Адрес `talking-heads-studio.lovable.app` из Redirect URL **уберите** — вход должен идти
только через iiavatar.ru (иначе снова будет ошибка «сменился IP»).

Нажмите «Сохранить».

### Шаг 3. Запросите доступы

Раздел называется «Доступы» (иногда «Доступ к данным» или «Права»).

Нужно включить или запросить четыре доступа:

| Доступ | Зачем |
|---|---|
| **Стена** (wall) | публиковать посты в сообществе |
| **Фотографии** (photos) | прикладывать обложки и картинки |
| **Видео** (video) | загружать ролики — **главное** |
| **Сообщества** (groups) | проверить, что вы администратор, и публиковать от имени сообщества |

- Если доступ можно просто включить переключателем — включите.
- Если рядом кнопка «Запросить» — нажмите. ВК попросит объяснить, зачем. Текст для заявки:

> Сайт iiavatar.ru — сервис производства видеороликов. Владелец сообщества ВКонтакте
> «ИИАВАТАР | Видео с ИИ-ведущим» (vk.com/club242478374) авторизуется через VK ID, чтобы
> сервис публиковал в это сообщество готовые ролики и посты от имени сообщества.
> Доступ используется только для публикации в собственное сообщество владельца, данные
> других пользователей не собираются.

- Сохраните. Если доступ ушёл на модерацию — статус будет «На рассмотрении».
  Обычно это от нескольких часов до нескольких дней.

### Шаг 4. Сообщите Claude

Напишите в чат, что получилось на шаге 3. Лучше скриншот раздела «Доступы» — по нему
видно, какие доступы включены, какие на модерации, какие отклонены.

**Пока «Видео» не одобрено — дальше не идём**, загрузка видео не заработает ни при каком коде.

## Часть 2. Код сайта — делает Claude (после одобрения доступов)

1. Сайт сам выполняет все запросы к ВК со своего сервера (iiavatar.ru): ключ ВК
   никуда не уходит с сервера, поэтому ВК не видит «смены IP».
2. Мост публикации отдаёт сайту только файл ролика, обложку и текст поста.
3. Готовится обновлённый архив сайта для вашего сервера + короткая инструкция по замене.

## Часть 3. Ваш сервер — делает тот, кто настраивал сервер (≈10 минут)

1. Заменить папку сайта новой сборкой (архив пришлёт Claude).
2. Проверить, что в настройках сервера есть ключи `TELEGRAM_BOT_TOKEN`,
   `TELEGRAM_CHAT_ID`, `VK_BRIDGE_KEY` (те же, что уже вписывали).
3. Перезапустить сайт.

## Часть 4. Один вход — делаете вы (1 минута)

1. Откройте **в окне инкогнито** `https://iiavatar.ru/api/vk?login=1`
   (именно этот адрес, не lovable.app).
2. Войдите под владельцем сообщества и **разрешите все запрошенные доступы**
   (если ВК покажет галочки — оставьте все включёнными).
3. Должно появиться «Готово ✅ Ключ ВК сохранён».
   Если ошибка — пришлите скриншот целиком: там будет причина и список выданных доступов.

## Часть 5. Проверка — делает Claude

1. Пробная загрузка короткого видео в сообщество (скрытого, потом удаляется).
2. Проверка клипов (вертикальной ленты): ВК может разрешать их загрузку не всем
   приложениям — если откажет, обычные видео будут публиковаться автоматически,
   а клипы останутся ручными.
3. После проверки — публикация по расписанию.
