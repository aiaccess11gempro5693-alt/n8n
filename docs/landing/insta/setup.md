# Instagram «ИИАВАТАР»: создание аккаунта и автопостинг

## Как будет работать автопостинг

```
Я готовлю публикацию (Reels / фото / карусель + подпись)
        ↓
GitHub Actions (мост — у меня нет прямого выхода в интернет)
        ↓  официальный Instagram API (Meta), ваш ключ — секрет IG_TOKEN
        ↓
Instagram: загрузка ролика → публикация
```

- Работает только официальный способ — **Instagram API с входом через Instagram**. Страница Facebook не нужна.
- Нужен **профессиональный аккаунт** (Бизнес или Автор) — у личного API нет.
- Reels загружаю файлом напрямую; фото и карусели Instagram забирает по ссылке — их положу на сайт (`iiavatar.ru/ig/...`).
- Лимит Instagram — до 50 публикаций через API в сутки, нам хватает с запасом.
- Ключ живёт 60 дней. Раз в ~50 дней я напомню, и вы за 2 минуты генерируете новый (шаги 2.5 и 3).

> В России Instagram заблокирован, а покупать в нём рекламу запрещено законом (с 01.09.2025).
> Публиковать свои ролики можно; продвигаемся только органикой (Reels, хештеги), без платной рекламы.
> Для шагов ниже нужен VPN; самому автопостингу VPN не нужен — мост работает с серверов GitHub.

## Шаг 1. Аккаунт

1. Создать аккаунт в приложении Instagram.
   - **Имя пользователя:** `iiavatar` (если занят — `iiavatar.ru` или `iiavatar_video`)
   - **Имя** (до 30 знаков): `ИИАВАТАР · Видео с ИИ-ведущим`
   - **Фото профиля:** `ig-avatar.jpg` (та же аватарка, что в ВК)
2. Настройки → «Тип аккаунта и инструменты» → **Переключиться на профессиональный** → **Бизнес**,
   категория — «Видеограф» (или «Маркетинговое агентство»).
3. **Описание** (113 / 150 знаков):

```
Видео с ИИ-ведущим из вашего текста 🎬
Reels, реклама, обучение — от 1 дня
От 1 000 ₽ за минуту
👇 Примеры и заявка
```

4. **Ссылки:** `https://iiavatar.ru` — «Сайт»; ссылка на Telegram-бота — «Написать в Telegram».
5. Кнопки контактов: почта/телефон — по желанию.

## Шаг 2. Приложение Meta (один раз)

1. Зайти на **developers.facebook.com** → «Начать» (нужен аккаунт Facebook — можно новый, к Instagram его привязывать не надо) → подтвердить почту/телефон.
2. **Мои приложения → Создать приложение**:
   - название: `IIAVATAR Autopost`;
   - сценарий: **«Управление сообщениями и контентом в Instagram»** (Manage messaging & content on Instagram);
   - тип: «Бизнес»; бизнес-портфолио — пропустить.
3. В приложении: **Instagram → Настройка API с входом через Instagram** (API setup with Instagram login).
4. Пункт «Создать токены доступа» → **Добавить аккаунт** → войти в `iiavatar` → разрешить доступ.
   Если просит роль: Роли приложения → «Тестировщики Instagram» → добавить `iiavatar`, затем в
   Instagram: Настройки → Приложения и сайты → Приглашения тестировщика → принять.
5. Нажать **«Сгенерировать токен»** напротив аккаунта → скопировать (длинная строка, начинается с `IG`).
   Публиковать приложение («Live») и проходить проверку Meta **не нужно** — для своего аккаунта
   хватает режима разработки.

## Шаг 3. Ключ в GitHub

Репозиторий n8n → Settings → Secrets and variables → Actions → New repository secret:

- Name: `IG_TOKEN`, Value: токен из шага 2.5.

Мне токен не присылать. Написать «готово» — проверю доступ (без публикации), затем первая публикация
только после вашего «да».
