# Что изменилось в финальных версиях ТЗ (21.08.2026)

Присланы Олегом: `Presentation_Pharma_Manufacturers_v4.docx` и финальный файл
по аптечным сетям. Предыдущие версии остались в `tz-manufacturers.txt` и
`tz-pharmacy-chains.txt`, новые — в файлах с суффиксами `-v4` и `-final`.

Правки в основном редакторские: реплики сокращены, списки местами
превращены в абзацы. Ниже — только содержательные изменения.

## Производители, v4

1. **Слайд 1.** Добавлено противопоставление тайному покупателю: «объективно
   и полностью, а не по выборке из пары визитов тайного покупателя».
2. **Слайд 4, порядок изменился.** «Как это устроено» теперь идёт первым,
   до описания услуг. «Правило эксклюзива» и «Горизонт — 3 месяца» вынесены
   из списка в отдельные абзацы. Формулировка эксклюзива сокращена.
3. **Слайд 5.** Оговорка про 1,2–1,4 раза переписана короче.
4. **Слайд 6, новое предложение.** «Это и есть смена концепции коммуникации
   с сетями — от переговоров вслепую к работе с полной картиной. Первому,
   кто её увидит, достанется вся выгода первого хода».

## Аптечные сети, финальная

1. **Слайд 1.** Добавлено «не создавая лишнего давления на команду».
2. **Слайд 3, крупное добавление.** Пункт про команду вынесен из списка,
   и добавлены три абзаца: экспертиза команды, сопровождение на всём
   партнёрстве, «строим результат вместе». Фактически новый подраздел.
3. **Слайд 4.** Список превращён в абзацы, «синтаксика» убрана.
4. **Слайд 5, новая строка.** «Все пять ролей смотрят в одни и те же данные
   под своим углом — вертикаль работает согласованно, а не вразнобой».
5. **Слайд 6, новая строка.** «Система не давит и не сравнивает с чужим
   идеалом…». В бонусном контуре «и почему» вместо «и где».
6. **Слайд 7.** «обучить команду без спешки»; «Плюс первый стол, который
   консультирует увереннее — без давления сверху».
7. **Слайд 9, новый абзац «Итог для сети»** — про синергию вертикали.

## Не изменилось и остаётся в силе

- Пометки «Что говорим» есть и в финальных версиях — на страницу не идут.
- В новом тексте слайда 3 по сетям появился ещё один служебный маркер
  «Важно добавить:» — на страницу идёт только текст после него.
- Оговорки про 1,2–1,4 и 1,3 раза сокращать нельзя: без них фразы
  превращаются в обещания, запрещённые 323-ФЗ.
