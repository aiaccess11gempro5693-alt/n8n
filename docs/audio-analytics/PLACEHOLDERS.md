# Плейсхолдеры и выдуманные данные — аудиоаналитика

Два лендинга: производители («Категорийный партнёр») и аптечные сети.
Файл ведётся, чтобы ничего выдуманного не уехало в прод.

## Требуют реальных данных

| Что | Где | Статус |
|---|---|---|
| Почта, телефон, сайт в футере | оба лендинга | ❌ Lovable выдумал `partner@pervystol.ru` и `+7 (495) 000-00-00`. Такого домена не существует. Заменено на явные заглушки, ждём настоящие контакты |
| Страница `/privacy` | оба лендинга | ссылка стоит, самой страницы нет; текст политики за клиента не пишем |
| Адрес приёма заявок (`formEndpoint`) | оба лендинга | пусто; пока пусто — форма открывает письмо на почту из футера |
| Логотип компании | оба лендинга | используется логотип CenterPharma; для аудиоаналитики принадлежность не подтверждена |

## Проверено и оставлено как есть

- «более 200 000 диалогов» — из ТЗ, реальная цифра.
- «в 1,2–1,4 раза чаще» (производители) и «в 1,3 раза чаще» (сети) — из ТЗ,
  приведены строго с оговоркой, что это наблюдение на записях, а не
  обязательство по договору. Оговорку сокращать нельзя: без неё фраза
  нарушает 323-ФЗ.
- Показатели в bento первого экрана (72 из 100, 4–5 отказов) — взяты
  из фактов ТЗ, не выдуманы.

## Правило

Если в промте не задано конкретное значение — Lovable его придумает.
Любые контакты, домены, названия клиентов и цифры задавать в промте явно
либо явными заглушками. Проверять футер и любые блоки с контактами после
каждой генерации.
