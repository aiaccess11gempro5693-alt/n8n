# Передача контекста: проект "Интерфейс" (Lovable + чат + оркестрация)

Эта сводка — для нового отдельного чата/проекта, где будет строиться веб-интерфейс с чатом (на Lovable), живым прогрессом генерации и подключением к реальной оркестрации (Claude Managed Agent + n8n). Подготовлена в основном чате проекта (см. `CLAUDE.md` в этом репозитории) по правилу ветвления крупных подзадач.

## Задача

Собрать веб-интерфейс (Lovable) с встроенным чатом:
1. Человек пишет в чат: "сделай видео про X" (или задаёт вопрос).
2. Сообщение уходит по API в n8n.
3. n8n запускает агента на Claude (Anthropic Managed Agents) — тот пишет сценарий, сам дёргает воркеров n8n (озвучка/картинки/аватар), сам монтирует финальное видео.
4. **Нужен живой прогресс** в чате по ходу генерации ("пишу сценарий… делаю картинки… монтирую…") — это НЕ мгновенный запрос-ответ, генерация занимает минуты.
5. Готовый результат (видео) возвращается в тот же чат; через него же можно продолжать диалог/просить доработки.

## Архитектура проекта целиком (контекст из основного чата)

- **n8n — это НЕ один автопайплайн, а набор независимых "воркеров"** (Webhook-адресов). Вся оркестрация — снаружи n8n.
- **Роли:** Claude (агент) — сценарий + монтаж; Gemini — дешёвая доработка промптов + проверка качества; Nano Banana — рендер картинок; ElevenLabs — озвучка; Heygen — аватар.
- Полное ТЗ на автономный конвейер (от руководителя Олега, 31.07.2026) — целиком приведено в `CLAUDE.md` этого репозитория, 15-шаговый процесс, статус по каждому пункту.

## Что уже сделано и реально работает (в этом репозитории)

- MVP-воркфлоу в n8n Cloud, **опубликован и работает**, 4 независимых воркера:
  - `POST /tts` — озвучка (ElevenLabs)
  - `POST /image` — промпт (Gemini) → картинка (Nano Banana) → проверка качества (Gemini)
  - `POST /avatar-start` — запуск генерации аватара (Heygen), возвращает `video_id`
  - `POST /avatar-status` — проверка статуса по `video_id`
  - Файл: `workflows/mvp-content-pipeline.json`. Формат запросов/ответов каждого — в `docs/SETUP.md`.
- Все credentials (ElevenLabs, Google AI Studio, HeyGen) привязаны в n8n.
- **Сами production-URL воркеров не хранятся в репозитории** (сознательно, см. правило безопасности в `CLAUDE.md`) — уточни их у пользователя заново, он их получал напрямую из n8n (Settings → откроется на каждой Webhook-ноде → Production URL).
- Черновой разбор тестового сценария на сцены (не дизайн-система!) — `docs/scenario-4-test-video.md`.

## Ключевые ограничения и решения, принятые ранее

1. **Этот (основной) чат/среда не имеет доступа к внешнему интернету** — sandboxed, прокси блокирует произвольные хосты (проверено на api.heygen.com и на самом n8n.cloud, оба дали 403). Именно поэтому нужен отдельный "агент с инструментами" с реальным доступом в сеть — либо Anthropic Managed Agents (хостится Anthropic), либо самостоятельный сервер с Claude Agent SDK.
2. **Managed Agents** (рекомендованный путь) — платный API-продукт Anthropic (не то же самое, что подписка Claude.ai/Pro — они не связаны и не покрывают друг друга). Даёт агента с инструментами (bash, файлы — значит и ffmpeg для монтажа) в облачном контейнере с настраиваемым сетевым доступом ("unrestricted"). Нужно: завести аккаунт на console.anthropic.com, привязать оплату, создать Agent + Environment, дальше на каждый запрос создавать Session.
3. **Стоимость:** оплата по токенам, не абонентка. Ориентир (Sonnet 5, льготная цена до 31.08.2026): $2/$10 за 1М токенов вход/выход. Прикидка — от нескольких центов до пары долларов за видео (агентный процесс тратит больше токенов, чем один вопрос в чате, т.к. включает рассуждения + вызовы инструментов, но ставка за токен та же).
4. Рассматривались сторонние реселлеры (CometAPI, Kie.ai) — дешевле на 20-50%, но скорее всего проксируют только обычные вызовы модели, а не сам продукт Managed Agents. Актуально только если пойдём по пути "свой сервер + Claude Agent SDK" — тогда можно направить его через такой прокси ради экономии.
5. **Ещё не найден** `avatar_id` для конкретного аватара "Avatar 3" в HeyGen (по указанию руководителя — тестировать только на нём). Нужно получить у пользователя (HeyGen → Avatars → открыть Avatar 3 → скопировать ID/URL).
6. **Webhook-и n8n сейчас без авторизации** — TODO добавить проверку секретного заголовка, прежде чем куда-либо публиковать их адреса.
7. **Дизайн-система (Шаг 0 из ТЗ) ещё не утверждена** — см. `CLAUDE.md`, раздел "Как устроено утверждение дизайн-системы". Это отдельный, ещё не пройденный процесс — Claude/Gemini должны предложить стиль/шаблоны/референсы/правила качества, человек утвердить.

## Что нужно сделать в новом чате

1. Решить: Anthropic Managed Agents (проще, платно по токенам) vs свой сервер с Claude Agent SDK (дешевле, но нужно администрировать) — см. п.2-4 выше.
2. Завести/настроить оплату на console.anthropic.com (если путь — Managed Agents).
3. Создать Agent (системный промпт — "видео-оркестратор" с полным доступом к инструментам) + Environment (cloud, unrestricted networking).
4. Продумать и собрать асинхронный/потоковый механизм показа прогресса в чате (Managed Agents умеет отдавать события по ходу сессии — SSE-стрим; нужно решить, как это доедет до фронтенда на Lovable — напрямую или через n8n-прослойку).
5. Собрать в n8n новый webhook-эндпоинт (например, `/orchestrate`), который принимает сообщение из чата и либо сам создаёт Managed Agent Session и проксирует события, либо просто передаёт задачу дальше.
6. Собрать сам интерфейс на Lovable: лендинг + встроенный чат, вызывающий этот n8n-эндпоинт, с отображением статуса и финального видео.
7. Не забыть: `avatar_id`, защита webhook-ов, вопрос дизайн-системы (можно решить и здесь, и в основном чате — на усмотрение).
