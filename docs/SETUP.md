# Настройка MVP-пайплайна (сценарий → озвучка → промпты+картинки+проверка качества)

Это первая версия проекта. Роли распределены так, чтобы не платить лишний раз за дорогое там, где справляется дешёвое:

1. **Claude Code (я, в чате)** — пишет сценарий (текст озвучки) и черновые описания сцен. Это творческая часть, требует реального рассуждения — остаётся за мной.
2. **Gemini** — берёт на себя всё, что может делать дёшево и механически: дорабатывает черновые описания сцен в детальные промпты для рендера картинок, а затем проверяет качество каждой готовой картинки (соответствует ли она промпту).
3. **Nano Banana** (модель генерации изображений Gemini) — просто рендерит пиксели по готовому промпту. Технически это тот же провайдер (Google), но роль другая: не "оркестрация/проверка", а исполнение.
4. **ElevenLabs** — озвучка текста.

Аватар (Heygen), монтаж видео и публикация — следующие шаги, добавим позже.

Везде, где написано "сделай сам" — шаги, которые нужно выполнить руками (регистрации, ключи). Всё остальное уже готово в файле `workflows/mvp-content-pipeline.json`.

## Шаг 1. Завести n8n Cloud

1. Открой https://n8n.io и нажми **Get started free** (или **Start for free**).
2. Зарегистрируйся (email или Google-аккаунт).
3. При создании инстанса выбери регион (любой ближайший, например Europe).
4. После создания откроется редактор n8n — это твой рабочий инструмент, дальше всё будет происходить в нём.

## Шаг 2. Получить API-ключ ElevenLabs — озвучка

1. Открой https://elevenlabs.io и зарегистрируйся (есть бесплатный тариф с ограниченным числом символов в месяц).
2. Зайди в профиль (иконка в правом верхнем углу) → **API Keys** → скопируй ключ.
3. (Опционально) Зайди в **Voice Library**, выбери голос, нажми **Copy Voice ID** — по умолчанию в воркфлоу уже стоит готовый голос "Rachel" (`21m00Tcm4TlvDq8ikWAM`), можно оставить как есть для теста.

## Шаг 3. Получить API-ключ Google AI Studio — Gemini (промпты + проверка качества) и Nano Banana (сами картинки)

1. Открой https://aistudio.google.com и войди через Google-аккаунт.
2. Нажми **Get API key** → **Create API key** → скопируй ключ.
3. Один и тот же ключ используется для трёх вещей: доработка промптов (Gemini), генерация картинок (Nano Banana) и проверка качества (Gemini) — регистрировать ничего отдельно не нужно.

## Шаг 4. Создать credentials в n8n

В n8n: **Settings** (значок шестерёнки внизу слева) → **Credentials** → **Add Credential**. Нужно создать две штуки, обе типа **Header Auth**:

| Название credential (важно называть именно так) | Header Name | Header Value |
|---|---|---|
| `ElevenLabs API` | `xi-api-key` | твой ключ из ElevenLabs |
| `Google AI Studio` | `x-goog-api-key` | твой ключ из Google AI Studio |

Для каждой: **Add Credential** → в поиске выбери **Header Auth** → впиши имя (колонка "Название" выше) → впиши Header Name и Header Value → **Save**.

## Шаг 5. Импортировать воркфлоу

1. В n8n слева **Workflows** → **Add workflow** → сверху справа троеточие (**...**) → **Import from File**.
2. Выбери файл `workflows/mvp-content-pipeline.json` из этого репозитория (скачай его себе на компьютер, если работаешь в облаке — например, через GitHub).
3. Воркфлоу откроется в редакторе со всеми нодами.

## Шаг 6. Привязать credentials к нодам

После импорта credentials нужно перевыбрать вручную (их ID не совпадают между аккаунтами):

- Нода **"1. Озвучка (ElevenLabs)"** → вкладка Credentials → выбери `ElevenLabs API`.
- Нода **"3. Уточнить промпт (Gemini)"** → выбери `Google AI Studio`.
- Нода **"5. Картинка (Nano Banana)"** → выбери `Google AI Studio`.
- Нода **"7. Проверка качества (Gemini)"** → выбери `Google AI Studio`.

## Шаг 7. Активировать воркфлоу и получить адрес Webhook

1. В правом верхнем углу редактора включи переключатель **Active** (воркфлоу должен постоянно "слушать" входящие запросы, а не запускаться только вручную).
2. Открой ноду **"0. Webhook: получить сценарий"**.
3. Скопируй **Production URL** (не Test URL — Test срабатывает только один раз при нажатии "Listen for test event", а Production работает всегда).
4. **Пришли этот URL мне (Claude Code) в чат.** Дальше каждый раз, когда попросишь сделать видео на какую-то тему, я сам сгенерирую сценарий и черновые описания сцен и отправлю их на этот адрес.

## Формат данных, которые я отправляю в Webhook

```json
{
  "topic": "тема (просто для логов)",
  "voiceover_text": "полный текст озвучки",
  "scene_descriptions": [
    "краткое описание сцены 1",
    "краткое описание сцены 2",
    "краткое описание сцены 3"
  ]
}
```

Описания сцен — черновые и короткие, их доработку в детальные промпты для рендера берёт на себя Gemini внутри n8n (ноды 3–4), мне для этого думать не нужно.

## Шаг 8. Тестовый запуск

Как только пришлёшь мне ссылку на Webhook — просто напиши, например: *"сделай видео про то, почему кошки любят коробки"*. Я подготовлю сценарий и черновые описания сцен и отправлю их в твой n8n. После выполнения:

- Нода **"1. Озвучка"** — на выходе бинарный файл `audio` (mp3), скачать можно прямо из панели выполнения (клик на ноду → вкладка бинарных данных → Download).
- Нода **"6. Base64 → файл изображения"** — сработает по одному разу на каждую сцену, на выходе бинарный файл `image` (png) для каждой — здесь же скачиваются готовые картинки.
- Нода **"7. Проверка качества"** — текстовый вердикт Gemini по каждой картинке ("OK" или описание проблемы). Если видишь не "OK" — можно попросить меня перегенерировать сценарий/сцену.

Если что-то пошло не так — открой **Executions** в n8n слева, там будет видно, на каком шаге ошибка (обычно это неправильно выбранный credential или неверный ключ).
