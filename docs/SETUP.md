# Настройка MVP-пайплайна (сценарий → озвучка → картинки)

Это первая версия проекта: по теме генерируется сценарий и промпты для картинок (через Claude), затем — озвучка (ElevenLabs) и картинки (Google Gemini / "Nano Banana"). Без аватара, монтажа и публикации — это следующие шаги.

Везде, где написано "сделай сам" — это шаги, которые нужно выполнить руками (регистрации, ключи). Всё остальное уже готово в файле `workflows/mvp-content-pipeline.json`.

## Шаг 1. Завести n8n Cloud

1. Открой https://n8n.io и нажми **Get started free** (или **Start for free**).
2. Зарегистрируйся (email или Google-аккаунт).
3. При создании инстанса выбери регион (любой ближайший, например Europe).
4. После создания откроется редактор n8n — это твой рабочий инструмент, дальше всё будет происходить в нём.

## Шаг 2. Получить API-ключ Anthropic (Claude) — генерация сценария и промптов

1. Открой https://console.anthropic.com и зарегистрируйся.
2. Слева в меню зайди в **Billing** и привяжи карту / пополни баланс (без этого API не работает; обычно есть небольшой стартовый бесплатный лимит).
3. Зайди в **API Keys** → **Create Key** → скопируй ключ (он показывается один раз, сразу сохрани).

## Шаг 3. Получить API-ключ ElevenLabs — озвучка

1. Открой https://elevenlabs.io и зарегистрируйся (есть бесплатный тариф с ограниченным числом символов в месяц).
2. Зайди в профиль (иконка в правом верхнем углу) → **API Keys** → скопируй ключ.
3. (Опционально) Зайди в **Voice Library**, выбери голос, нажми **Copy Voice ID** — по умолчанию в воркфлоу уже стоит готовый голос "Rachel" (`21m00Tcm4TlvDq8ikWAM`), можно оставить как есть для теста.

## Шаг 4. Получить API-ключ Google AI Studio — генерация картинок (Gemini / "Nano Banana")

1. Открой https://aistudio.google.com и войди через Google-аккаунт.
2. Нажми **Get API key** → **Create API key** → скопируй ключ.
3. "Nano Banana" — это неофициальное прозвище модели генерации изображений Gemini (`gemini-2.5-flash-image`), доступной по этому же ключу.

## Шаг 5. Создать credentials в n8n

В n8n: **Settings** (значок шестерёнки внизу слева) → **Credentials** → **Add Credential**. Нужно создать три штуки, все типа **Header Auth**:

| Название credential (важно называть именно так) | Header Name | Header Value |
|---|---|---|
| `Anthropic API` | `x-api-key` | твой ключ из Anthropic Console |
| `ElevenLabs API` | `xi-api-key` | твой ключ из ElevenLabs |
| `Google AI Studio` | `x-goog-api-key` | твой ключ из Google AI Studio |

Для каждой: **Add Credential** → в поиске выбери **Header Auth** → впиши имя (колонка "Название" выше) → впиши Header Name и Header Value → **Save**.

## Шаг 6. Импортировать воркфлоу

1. В n8n слева **Workflows** → **Add workflow** → сверху справа троеточие (**...**) → **Import from File**.
2. Выбери файл `workflows/mvp-content-pipeline.json` из этого репозитория (скачай его себе на компьютер, если работаешь в облаке — например, через GitHub).
3. Воркфлоу откроется в редакторе со всеми нодами.

## Шаг 7. Привязать credentials к нодам

После импорта credentials нужно перевыбрать вручную (их ID не совпадают между аккаунтами):

- Открой ноду **"2. Сценарий + промпты (Claude)"** → вкладка Credentials → выбери `Anthropic API`.
- Открой ноду **"4. Озвучка (ElevenLabs)"** → выбери `ElevenLabs API`.
- Открой ноду **"6. Картинка (Gemini / Nano Banana)"** → выбери `Google AI Studio`.

## Шаг 8. Тестовый запуск

1. Открой ноду **"1. Ввод данных"** и при желании поменяй тему/стиль/количество картинок.
2. Нажми **Test workflow** (кнопка вверху).
3. После выполнения:
   - Нода **"4. Озвучка"** — на выходе будет бинарный файл `audio` (mp3), его можно скачать прямо из панели выполнения (клик на ноду → вкладка бинарных данных → Download).
   - Нода **"7. Base64 → файл изображения"** — сработает по одному разу на каждый промпт из списка, на выходе бинарный файл `image` (png) для каждого.

## Что дальше (после того как MVP заработает)

Следующие шаги по плану:
- Генерация аватара (Heygen) поверх картинок/сценария.
- Монтаж видео: субтитры, склейка изображений/видео, вставка аудио.
- Проверка качества (через Gemini/оркестратор).
- Публикация в VK, Instagram, на сайт + сохранение в хранилище.

Каждый из этих шагов потребует новых регистраций/ключей — будем добавлять по мере готовности предыдущих.
