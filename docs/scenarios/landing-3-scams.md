# Лендинг, ролик 3 — «Как не попасться телефонным мошенникам»

**Ниша:** экспертный контент. **Длительность:** 9:16 — до 30 с, 16:9 — до 60 с.
**Стиль:** «Reels-эксперт» (`scratch/img/l2_board_reels.png`): чёрный #0E0E10 /
кислотный жёлтый #FFE600 / алярм-красный #FF3B30 / белый / серый #8E8E93,
Unbounded Black + Montserrat ExtraBold, штампы, жёлтые мазки, крупные субтитры со
словом-подсветкой. Файл стиля — `render/landing/theme_reels.py`.
**Персонаж:** эксперт по кибербезопасности банка, мужчина ~40, чёрная рубашка,
чёрный фон с жёлтым/красным контровым светом (`docs/scenarios/landing-3/images-character.json`).
Без бейджа и имени — экспертность несёт подача.
**Факты:** только общеизвестные — банк не спрашивает код из СМС; «безопасного
счёта» не существует; положить трубку и перезвонить по номеру с карты. Без
названий банков и брендов.

Теги в квадратных скобках — интонация для ElevenLabs `eleven_v3`, в субтитры не идут.

## Текст 9:16 (до 30 с)

Хук → 3 признака → что делать → итог.

[confident] Вам звонят из «службы безопасности банка», и голос звучит очень убедительно. [firmly] Запомните три признака мошенника. [clear] Первый: торопит и пугает. [clear] Второй: просит код из СМС — [with quiet conviction] банк его никогда не спрашивает. [clear] Третий: предлагает перевести деньги на «безопасный счёт». [firmly] Такого счёта не существует. [confident] Что делать? Положите трубку и перезвоните в банк сами — по номеру на обратной стороне карты. [warmly] Минута паузы сбережёт ваши деньги.

## Раскладка 9:16 (своя, не как в ролике 1)

| Сцена | Реплика | Раскладка |
|---|---|---|
| 1 хук | «Вам звонят из службы безопасности банка…» | эксперт на весь кадр; сверху — карточка входящего звонка «Служба безопасности банка» с пульсом, по слову «убедительно» на неё падает штамп **«ОПАСНО»** |
| 2 | «Запомните три признака» | без эксперта: огромная жёлтая **«3»** + «признака мошенника» на жёлтом мазке |
| 3 | признаки 1–2 | эксперт сдвинут вниз и вправо; слева сверху стопка «стикеров»: ① «Торопит и пугает» (иконка молнии) → ② «Просит код из СМС» + красный перечёркнутый «код ••••» и плашка «банк не спрашивает» |
| 4 | признак 3 | крупный план лица в жёлтой рамке-«видоискателе» вверху; ниже — «Безопасный счёт» и красный крест/штамп «НЕ СУЩЕСТВУЕТ» |
| 5 | «Что делать?» | эксперт слева, справа сверху — две большие кнопки звонка: красная «положите трубку» → жёлтая «перезвоните сами» + мини-карта с подсвеченным номером на обороте |
| 6 итог | «Минута паузы…» | эксперт на весь кадр, над головой — «1 минута паузы = ваши деньги целы» на жёлтом мазке |

Субтитры — крупные (Montserrat ExtraBold ~64), белые на чёрной плашке, **текущее
слово подсвечено жёлтым** (стиль Reels, решение для примеров сайта 05.10.2026).
Переход — жёлтый мазок кисти, пролетающий через кадр.
