# Instagram Reels №2 «Вы забудете это видео» (9:16, ~40 с)

Серия продающих Reels `iiavatar.video` (`docs/landing/insta/content-plan.md`).
Формула — сюжет с открытой петлёй: крючок → интрига «приём расскажу в конце» →
**реклама в середине** (такого ведущего соберём и вам) → обещанная развязка в конце,
ради которой досматривают. Слово для директа — «ВЕДУЩИЙ».
Тема нейтральная и полезная: кривая забывания и интервальные повторения.

## Текст (чистая речь, для субтитров)

Вы забудете это видео через час. И это не ваша вина — так устроен мозг.
Ещё в девятнадцатом веке психолог Герман Эббингауз проверил это на себе:
уже через сутки мы теряем больше половины нового.
Поэтому одна лекция или один инструктаж почти ничего не меняют.
Но есть простой приём, который ломает эту кривую. Он — в конце.
Кстати, ведущую этого ролика собрали нейросети. Такую же сделаем и для вас:
для обучения сотрудников, для блога, для любой задачи. Пишите «ведущий» в директ.
А теперь — обещанный приём.
Повторяйте не сразу, а с паузами: через день, через три дня, через неделю.
Каждый раз знание возвращается почти целиком и держится всё дольше.
Отправьте это видео тому, кто сейчас учится.

## Раскадровка (черновик)

| Блок | Кадр |
|---|---|
| Крючок | ведущая крупно, «ВЫ ЗАБУДЕТЕ ЭТО ВИДЕО», таймер «1 час» |
| Эббингауз | график-кривая забывания, линия падает, «−50% за сутки» |
| Интрига | «Приём — в конце» + полоса прогресса |
| Реклама | ведущая в круге, «Такого ведущего — вам»: обучение · блог · любые задачи, «ВЕДУЩИЙ» в директ |
| Развязка | тот же график: на каждом повторении кривая подскакивает вверх — «1 день · 3 дня · неделя» |
| Финал | «Отправьте тому, кто учится» |
