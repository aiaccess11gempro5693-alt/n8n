# Instagram Reels №1 «Меня не существует» (9:16, ~28 с)

Серия продающих Reels `iiavatar.video` — см. `docs/landing/insta/content-plan.md`.
Формула: крючок → польза → раскрытие «я ИИ» → призыв. Слово для директа — «ВЕДУЩИЙ».

## Текст (чистая речь, для субтитров)

Стоп. Две секунды — столько у меня есть, чтобы вы не пролистали.
Получилось? Тогда три правила видео, которое досматривают.
Первое: лицо в кадре. Мы смотрим на людей, а не на текст.
Второе: одна мысль — одна сцена.
Третье: субтитры. Многие смотрят ленту без звука.
И кстати… меня не существует.
Ни камеры, ни студии — я нейросеть, а этот ролик собран из текста за один день.
Хотите такого ведущего для своего бизнеса? Напишите «ведущий» в директ.
