# Лендинг, ролик 4, виток 2 — «Ужин из видео»: сервис «Повтори»

Решение 07.10.2026: сюжет «сборщик / доставка за 60 минут» отклонён («такие
доставки сто лет как есть», голос, мало ведущего, обрезанные плечи). Новая
концепция — актуальная для Москвы 2026: нейросеть превращает видео-рецепт из
ленты в готовую корзину, учитывает, что уже есть дома, курьер — за 15 минут.

**Сервис:** вымышленный «Повтори» («увидела — повторила»). Без реальных брендов;
соцсети не называем (Meta — экстремистская в РФ): «рецепт в ленте».
**Стиль:** A «Свежий рынок» (`scratch/img/l4_board2_a.png`, `render/landing/theme_product.py`).
**Героиня:** молодая московская фуд-блогерша (варианты — шаг 2). В кадре больше и
крупнее, кадр с запасом по плечам и рукам.
**Голос:** живой, разговорный, «как у блогера» (пробы — шаг 2).
