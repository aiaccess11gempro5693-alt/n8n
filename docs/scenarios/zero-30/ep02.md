# Серия 2 «День второй: лёгкие деньги»

~1:30, 9:16, без ведущего, стиль A «Ночной город» (`scratch/img/z30_board_night.png`), голос Синев
`mGnyEHBfaNztXxZkkMKN` (eleven_v3, stability 0.3), как серия 1.

Приёмы удержания: в первые секунды — обещание «сегодня тебе предложат деньги, и это будет ловушка»;
по ходу два «уровня» с наградой (минус подписки, первые деньги); ложная удача («покупатель берёт
без торга!») → разоблачение мошенника → настоящая удача → крючок на серию 3 («позвонит служба
безопасности банка — ты возьмёшь трубку?»). Польза: проверить все подписки; деньги за один день
физической помощью; продавцу не нужно вводить данные карты, чтобы получить деньги.

Баланс: −399 ₽ (из серии 1) → +1 101 ₽ (1 500 наличными за переезд).
