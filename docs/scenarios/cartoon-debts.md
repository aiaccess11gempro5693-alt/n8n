# Мультсериал «Саша: 30 дней без долгов» (идея №27 из 30)

Механика по чужому залетевшему ролику (TikTok @skuf.dima «Скуф Дима | 30 дней челлендж», 49,5K лайков, 10,3K комментариев;
захват страницы — `docs/landing/insta/refs/ref-tt-1.json`, `scratch/img/competitors/ref_tt_1/`):
- плоский мультяшный герой с узнаваемой слабостью;
- сериал с обратным отсчётом («День 5 из 30»);
- игровая панель сверху (в референсе «до встречи 26 / прокачка 6 % / вес 125 кг»);
- зрители выбирают следующий шаг героя в комментариях → много комментариев.

Наша история: Саша (около 30 лет) за 30 дней выбирается из кредитов. Панель: «ДОЛГ, ₽ / ДНЕЙ ОСТАЛОСЬ / СОБЛАЗНЫ».
Каждый выпуск 30–60 с: что выбрали вчера → что из этого вышло → полезный финансовый совет → новый выбор
(«купить или отложить?») в комментарии. Внутри — реальные советы по личным финансам, без обещаний и без
рекомендаций конкретных банков/продуктов.

Технически: герой — gpt-image-2 (мультяшный, фронтально, губы приоткрыты, по пояс) → HeyGen photo avatar →
голос ElevenLabs eleven_v3; панель и выбор рисуются кодом в монтаже.
