# Серия «Представь: у тебя 0 ₽ и 30 дней»

Идея №3 из предложенных 09.11.2026 по чужому ролику (TikTok @mfg2_0_2_5 «Представь: просыпаешься на 14-м этаже —
выживание в апокалипсисе», 169,8K лайков, 1 162 комментария; захват — `docs/landing/insta/refs/ref-tt-2.json`,
`scratch/img/competitors/ref_tt_2/`).

Механика референса: **зритель — главный герой** («представь… ты…»), правила выживания по дням, плоская
минималистичная анимация без ведущего, голос рассказчика, крупные субтитры с ключевым словом цветом.

Наша история: ты просыпаешься — на карте ровно 0 ₽, до зарплаты 30 дней, занять не у кого. Каждая серия ~60 с —
один день (или несколько): ситуация → 2–3 правила с реальной пользой (еда, транспорт, первый заработок, ловушки
микрозаймов и подписок) → крючок в конце («часть N завтра») + вопрос зрителю «что бы ты сделал?».

Отличие от мультсериала про Сашу (`cartoon-debts.md`): нет героя-ведущего и HeyGen — герой «ты», без лица;
нет голосования А/Б — вопрос открытый; анимация собирается монтажом из кадров gpt-image-2.

Без обещаний заработка и без рекомендаций конкретных банков/сервисов. Суммы реалистичные для 2026.
