# Reels №35 «Тетрис: игра, за которую автор не получил ни копейки»

Формат и движок — как у №32 «Прайм Москвы» (неоновая моушн-графика кодом, без ведущего, рамка «▶ PLAY / дата»,
крупные субтитры с подсвеченным словом), по просьбе пользователя — «на другую интересную тему в этом же стиле,
с классной музыкой». Музыка — чиптюн из библиотеки HeyGen.

Факты (проверены): Тетрис придуман Алексеем Пажитновым в 1984 г. в Вычислительном центре АН СССР на компьютере
«Электроника-60» (текстовый экран, фигуры из скобок); название — «тетра» (четыре) + теннис; игра разошлась по
СССР на дискетах, затем через Венгрию — на Запад; права на программы сотрудников принадлежали государству
(«Элорг»); в 1989 г. Nintendo в США комплектовала Game Boy картриджем Тетриса; версия для Game Boy — более
35 млн копий; Пажитнов не получал отчислений до 1996 г., когда права вернулись к нему (The Tetris Company).

Голос — Синев `mGnyEHBfaNztXxZkkMKN` (eleven_v3, stability 0.0 — ярко, как №32).
