# Серия Reels «История России» — правила

Решения пользователя (02.11.2026). Читать перед каждым роликом серии.

1. **Один ведущий и один голос на всю серию.** Рисованный дедушка-летописец
   (`scratch/img/hist_toon_c.png`, HeyGen photo avatar `90034b8bf09a9a05b46b46591b1aeb89`,
   Avatar IV + expressiveness high + motionPrompt), голос Станислав `ogi2DyUAKJb7CEdqqvlU`
   (eleven_v3). Тёплая живописная «сказочная» иллюстрация, формат 9:16.
2. **Кроме ведущего ничего не генерируем.** В кадре только настоящие картинки — Wikimedia
   Commons с открытой лицензией (`tools/web_images.py`, режим `web_images`), лицензия
   записывается в `scratch/img/web/<set>/index.json`, в подписи поста — «Wikimedia Commons».
   Обложка — тоже из настоящих картинок + кадр ведущего, рисуется кодом (не gpt-image-2).
3. **Движение — монтажом:** вырезать фигуры (rembg) и двигать их по кадру, наезды, панорамы.
4. **Без звука «вжух» на сменах картинок** (замечание к №1) — эффекты перелистывания не
   ставим, только тихая музыка под голос.
5. **Меньше картинок, меньше мелькания** (замечание к №1, там было 9 смен за 55 с): не больше
   5–6 картинок на ролик, каждая держится ≥4–5 с; одну картинку можно разглядывать дольше
   (наезд/панорама по деталям) вместо смены на новую; чаще возвращаться к ведущему.
6. Озвучка: whisper-1 — дословность; Gemini (`tools/check_audio.py`) — ударения; неверное
   слово переозвучивается одной фразой и вклеивается в паузы (длина дорожки та же).
7. Текст и графика — в зоне 250–1500 px; надписи не на лице ведущего (крючок/призыв — на груди).
8. Файл: без шума `noise` (раздувает до сотен МБ), crf 21 + maxrate 9M.
9. **Обложки серии не повторяют друг друга** (замечание к №2, 02.11.2026: две обложки подряд
   с одним и тем же крупным дедушкой в ленте выглядят почти одинаково — пост №2 пользователь
   удалила). Главное на обложке — настоящая картинка темы ролика (находка, картина, фото
   места), крупно и у каждого ролика своя; дедушку не ставить главным планом (можно не ставить
   совсем или маленьким кружком-«печатью» серии). Заголовок — разной раскладки и цвета
   плашки от ролика к ролику, чтобы в сетке профиля обложки соседних роликов отличались с
   первого взгляда. Перед публикацией сравнить новую обложку с обложками двух предыдущих.

## Как делается один ролик (по шагам)

1. Сценарий с проверенными фактами и разметкой eleven_v3 — `docs/scenarios/history/NN-*.md`.
2. Озвучка (мост `call-elevenlabs-api.yml`, голос Станислав) → whisper-1 (`call-cometapi-transcribe.yml`)
   → обрезка «Пока-пока» по последней паузе → Gemini-проверка ударений (`audio_check`).
3. Картинки: `web_images` (поиск/точные файлы Commons, вырезание фона) → смотреть контакт-лист,
   брать 4–5 лучших, лицензия в `index.json`.
4. HeyGen: загрузить обрезанную озвучку как asset → `create_video_from_avatar`
   (avatar `90034b8bf09a9a05b46b46591b1aeb89`, avatar_iv, expressiveness high, motionPrompt, 9:16,
   1080p) → скачать через `fetch-url.yml`.
5. Монтаж `render/landing/build_histNN.py` (общие функции — `build_hist01.py`), пробная сборка
   с временным клипом, проверка кадров, финальная сборка.
6. Отправить пользователю → после «выкладывай»: обложка по п.9 → видео и обложка в хранилище
   HeyGen → пост `docs/landing/insta/posts/NNN-histNN-*.json` → `ig-post.yml`.
