Метод (`docs/clients/apiksanta/storyboard-build/render_video.py`): After Effects здесь не запустить, поэтому база — исходный рендер клиента (шрифты/анимация/тайминг/звук 1 в 1), а исправленные элементы покадрово отслеживаются в оригинале и заменяются с тем же движением:
- капсула логотипа — на всех кадрах, проявляется вместе с логотипом (0–0.7 с);
- свиток титула (2.5–8 с) — въезд = горизонтальное «разворачивание» (масштаб по X, точный трекинг ECC по самой заменяемой строке), уход = наезд + растворение; исправление накладывается разностью с измеренной прозрачностью;
- плашки титула — «шторка» проявления текста слева направо замеряется по колонкам оригинальной строки и переносится на новую строку; старый текст убирается только там, где плашка уже раскрыта;
- сноски титула — старый текст вычитается (unmix), новый ставится с той же прозрачностью слоя (появление 2.6–3.3 с, уход 7.4–7.9 с);
- слайд 3 (8.4–43 с) — блок сносок поднят на строку, строка ОХЛП с прозрачностью блока; «**» едут за подписью «АПИКСАНТА 2,5мг…» на всём пути (13–24 с крупно, 25–27 с переезд, 36–38 с финальный сдвиг);
- финал — код APIX-RU-00148-DOC-11.2026 проявляется вместе с «Благодарим за внимание» (293–294 с).
