Videovideo.save

Метод получает адрес сервера, на который необходимо загрузить видео, а также данные этого видео.

Примечание. Приложение может вызвать этот метод не более 5 000 раз в сутки.

Для вызова метода можно использовать:
• ключ доступа пользователя (требуется право доступа: video — выдаётся в исключительных случаях через запрос в поддержку по электронной почте devsupport@corp.vk.com)
Параметры
name

string

Необязательный параметр. Название видеофайла. Максимальное количество символов — 128.

description

string

Необязательный параметр. Описание видеофайла. Максимальное количество символов — 5 000.

is_private

checkbox

Необязательный параметр. Информация о том, можно ли будет отправлять загруженное видео личным сообщением. Возможные значения:

•
1 — загрузить видео, которое можно будет отправлять личным сообщением.
•
0 — загрузить видео, которое нельзя будет отправлять личным сообщением. Значение используется по умолчанию.

Примечание. Если загрузить видеофайл с этим параметром, видео не будет отображаться в списке видео пользователя и не будет доступно другим пользователям по идентификатору видео.

wallpost

checkbox

Необязательный параметр. Информация о том, опубликовать ли после сохранения запись с видео на стене. Возможные значения:

•
1 — опубликовать запись с видео на стене.
•
0 — не публиковать запись с видео на стене.
link

string

Необязательный параметр. URL источника видеозаписи. Используется для встраивания видео с внешних сайтов, например с YouTube.

Примечание. Если вы передаёте этот параметр, отправьте POST-запрос на полученный в методе video.save параметр upload_url без прикрепления видеофайла. Достаточно просто обратиться по этому адресу.

group_id

integer

Необязательный параметр. Идентификатор сообщества, в список видео которого будет сохранён видеофайл. По умолчанию видео сохраняется в список видео текущего пользователя.

album_id

positive

Необязательный параметр. Идентификатор альбома, в который будет загружено видео.

privacy_view

string

Необязательный параметр. Настройки приватности просмотра видео. Указывается в специальном формате. Параметр используется для видео, которые пользователь загрузил в свой профиль.

Примечание. Параметр может указывать настройки приватности сообществ, если видео принадлежит сообществу.

privacy_comment

string

Необязательный параметр. Настройки приватности комментирования видео. Указывается в специальном формате. Параметр используется для видео, которые пользователь загрузил в свой профиль.

Примечание. Параметр может указывать настройки приватности сообществ, если видео принадлежит сообществу.

no_comments

checkbox

Необязательный параметр. Информация о том, нужно ли отключить возможность комментирования видео из сообществ. Возможные значения:

•
1 — отключить возможность комментирования.
•
0 — не отключать возможность комментирования. Значение используется по умолчанию.
repeat

checkbox

Необязательный параметр. Информация о том, нужно ли зациклить воспроизведения видео. Возможные значения:

•
1 — зациклить видео.
•
0 — не зацикливать видео.
compression

checkbox

ord_info

text

auto_publish

checkbox

donut_level_id

integer
