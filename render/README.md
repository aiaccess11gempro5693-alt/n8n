## Что есть в `render/corner/`

- `geometry.py` — геометрия перехода "аватар на весь кадр → уезжает в
  правый нижний угол", позиция субтитровой плашки в обеих фазах,
  свободная зона под плашку с инфографикой/буллитами.
- `brand_style.py` — дизайн-токены нового брендбука (палитра/шрифты) —
  см. `docs/references/oleg-brand-board-*.jpg`.
- `static_captions.py` — субтитры БЕЗ караоке-подсветки слов (прямое
  требование, см. `CLAUDE.md`) — целый текстовый чанк меняется разом.
- `plashka.py` — PIL-компоненты для плашки (буллит-карточка,
  quote-карточка) в новой палитре.
