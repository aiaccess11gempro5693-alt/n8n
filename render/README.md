# Монтажный конвейер (ffmpeg-рендер)

Рабочий код финальной сборки видео — субтитры, иконки, заголовки, склейка.
Раньше жил только в сессионной scratchpad-папке (`/tmp/...`) и терялся между
сессиями; с 17.09.2026 закоммичен сюда, чтобы быть переиспользуемым для
любого следующего ролика, а не только для тестового "Сценарий 4, иммунитет".

Правила/стиль, которые этот код реализует, зафиксированы в
`../docs/design-system.md` — этот README про то, **как запускать**, design-system
про то, **что должно получиться**.

## Требуемые входные данные (готовятся заранее, не этим кодом)

- `/tmp/final-scenes/scene-N.mp4` (N=1..8) — сырые клипы аватара от HeyGen
  (`avatar_iii`, лип-синк по `audio_asset_id`, см. `../CLAUDE.md` про
  архитектуру ElevenLabs→HeyGen-asset→HeyGen-лип-синк).
- `../scratch/sceneN-iconM.png` — изолированные иконки на пурпурном фоне
  `0xE91E8F` (сгенерированы через `.github/workflows/call-image-pipeline.yml`,
  прошли QA-гейт — см. design-system.md, правило "QA-вердикт — это гейт").

## Порядок запуска (по одному сценарию)

**С 17.09.2026 финальная сборка — один скрипт, `build_trend_video.py`**
(см. design-system.md, раздел "Динамика кадра и переходы"). Он заменяет
старую связку из 4 отдельных шагов (render_scenes.sh → render_icon_scenes.py
→ render_headlines.py → build_concat_cmd.py) на один проход: Ken Burns-зум
+ точечный punch-in на аватаре, иконки-стикеры, кроссфейды без "призраков"
текста на стыках сцен, субтитры и overshoot-заголовки единым текстовым
слоем поверх уже склеенного видео. Старые 4 скрипта оставлены в репозитории
для истории/справки (их отдельные технические приёмы — crop-маска
субтитров, генератор pill, стикер-иконки — переиспользуются напрямую
внутри `build_trend_video.py`), но для сборки ролика не вызываются.

```bash
cd render/

# 1. Посчитать тайминги слов и разбивку субтитров на чанки —
#    правит NARRATION{} и DURATIONS{} внутри под новый сценарий.
python3 compute_word_layout.py

# 2. Сгенерировать pill-подписи под иконками (стикер-стиль: белая обводка
#    через dilation альфа-маски + мягкая тень, появление синхронизировано
#    с word_layout.json). Правь список labels[] внутри под новый сценарий.
python3 pill_gen_all.py

# 3. Собрать весь ролик целиком: Ken Burns+punch на каждой сцене, иконки,
#    кроссфейды, субтитры (crop-маска), overshoot-заголовки — на общем
#    таймлайне, с "тихой" зоной текста вокруг каждого перехода (см. ниже).
#    Правь под новый сценарий: PUNCH{} (какие 1-2 реплики за весь ролик
#    получают punch-in), ICON_SCENES/defs2..defs6 (список
#    иконок/подписей/позиций/тайминга — скопировано из старого
#    render_icon_scenes.py, там же исторический референс), SCENE_KIND
#    (тип перехода между сценами). Текст заголовков по-прежнему берётся
#    из render_headlines.py::PLAN (импортируется напрямую).
python3 build_trend_video.py
# результат: full-trend-video.mp4 — скопировать в ../scratch/ с версией
```

## Правка под новый сценарий — что где менять

| Что нужно поменять | Файл |
|---|---|
| Текст реплик по сценам, длительности клипов | `compute_word_layout.py` (`NARRATION`, `DURATIONS`) |
| Список иконок/подписей/позиций/цветов/тайминга на сцену | `build_trend_video.py` (`ICON_SCENES`/`defs2..defs6` внутри) |
| Текст/тайминг заголовков главной мысли | `render_headlines.py` (`PLAN`) — импортируется в `build_trend_video.py` |
| Какие 1-2 реплики получают punch-in зум | `build_trend_video.py` (`PUNCH{}`) |
| Порядок сцен, тип перехода между ними | `build_trend_video.py` (`scenes`, `SCENE_KIND`) |
| Палитра/шрифт/толщина обводки-стикера | `pill_gen_all.py` (`TEAL`, `CORAL`), `build_trend_video.py` (счётчик `dilation` в `render_icons()`) |

## Файлы

- `compute_word_layout.py` — считает тайминги слов диктора (для караоке-подсветки
  и для синхронизации появления иконок/заголовков с речью), пишет `word_layout.json`.
- `caption_filter.py` — исторический генератор filter_complex для субтитровой
  плашки одной сцены (crop-маска караоке-подсветки); сама техника теперь
  встроена прямо в `build_trend_video.py` (работает на общем таймлайне всех
  сцен сразу), этот файл — справочный.
- `pill_gen_all.py` — генератор скруглённых pill-бейджей (PIL): подписи под
  иконками И заголовки главной мысли используют один и тот же генератор/стиль.
- `render_scenes.sh`, `render_icon_scenes.py`, `render_headlines.py` (сама
  функция рендера, не `PLAN`), `build_concat_cmd.py` — старая (до 17.09.2026)
  4-шаговая сборка. Не вызывать для новой сборки — оставлены для истории и
  как источник некоторых приёмов, которые `build_trend_video.py`
  переиспользует. `render_headlines.py::PLAN` — по-прежнему живой источник
  текста/таймингов заголовков, импортируется напрямую.
- `build_trend_video.py` — актуальная финальная сборка (шаг 3 выше): Ken
  Burns+punch, иконки-стикеры, кроссфейды без наложения текста на стыках,
  субтитры + overshoot-заголовки на общем таймлайне.
- `fonts/Inter-Bold.otf` — единственный шрифт во всём ролике (субтитры,
  подписи, заголовки — везде один и тот же файл).
- `ambient_bed.m4a` — фоновая музыка (микшируется тихо под озвучку).
