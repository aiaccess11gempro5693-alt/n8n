# Монтажный конвейер (ffmpeg-рендер)

Рабочий код финальной сборки видео — субтитры, иконки, заголовки, склейка.
Раньше жил только в сессионной scratchpad-папке (`/tmp/...`) и терялся между
сессиями; с 17.09.2026 закоммичен сюда, чтобы быть переиспользуемым для
любого следующего ролика, а не только для тестового "Сценарий 4, иммунитет".

Правила/стиль, которые этот код реализует, зафиксированы в
`../docs/design-system.md` — этот README про то, **как запускать**, design-system
про то, **что должно получиться**.

## Требуемые входные данные (готовятся заранее, не этим кодом)

- `/tmp/final-scenes/scene-N.mp4` (N=1..8) — сырые клипы аватара от HeyGen
  (`avatar_iii`, лип-синк по `audio_asset_id`, см. `../CLAUDE.md` про
  архитектуру ElevenLabs→HeyGen-asset→HeyGen-лип-синк).
- `../scratch/sceneN-iconM.png` — изолированные иконки на пурпурном фоне
  `0xE91E8F` (сгенерированы через `.github/workflows/call-image-pipeline.yml`,
  прошли QA-гейт — см. design-system.md, правило "QA-вердикт — это гейт").

## Порядок запуска (по одному сценарию)

```bash
cd render/

# 1. Посчитать тайминги слов и разбивку субтитров на чанки —
#    правит NARRATION{} и DURATIONS{} внутри под новый сценарий.
python3 compute_word_layout.py

# 2. Отрендерить сцены-только-аватар (без иконок) + субтитры.
#    Функции render_scene_N_icons внутри — УСТАРЕВШИЕ (старый стиль белой
#    карточки), не вызывать; актуальный рендер icon-сцен — шаг 3.
bash render_scenes.sh

# 3. Сгенерировать pill-подписи под иконками и отрендерить icon-сцены
#    (стикер-стиль: белая обводка через dilation альфа-маски + мягкая тень,
#    появление синхронизировано с word_layout.json, подписи — pill-бейджи).
#    Правь список icons/labels/timing внутри под новый сценарий.
python3 pill_gen_all.py
python3 render_icon_scenes.py

# 4. Наложить заголовки главной мысли (pill-бейдж, левый верхний угол,
#    обновляется по смысловым блокам, гаснет только если угол сцены занят
#    иконкой). Правь словарь PLAN{} внутри под новый сценарий — timing
#    берётся из word_layout.json (когда начинается каждая мысль), end=None
#    значит "до конца сцены", end=T значит "погасить перед иконкой в T".
python3 render_headlines.py

# 5. Собрать финальный ролик (кроссфейды между сценами, фоновая музыка).
python3 build_concat_cmd.py
bash concat_cmd.sh
# результат: final_test_video.mp4 — скопировать в ../scratch/ с версией
```

## Правка под новый сценарий — что где менять

| Что нужно поменять | Файл |
|---|---|
| Текст реплик по сценам, длительности клипов | `compute_word_layout.py` (`NARRATION`, `DURATIONS`) |
| Список иконок/подписей/позиций/цветов/тайминга на сцену | `render_icon_scenes.py` (`scene*_icons` списки в самом низу) |
| Текст/тайминг заголовков главной мысли | `render_headlines.py` (`PLAN`) |
| Порядок сцен, тип перехода между ними | `build_concat_cmd.py` (`scenes`, `SCENE_KIND`) |
| Палитра/шрифт/толщина обводки-стикера | `pill_gen_all.py` (`TEAL`, `CORAL`), `render_icon_scenes.py` (счётчик `dilation` в filter-цепочке) |

## Файлы

- `compute_word_layout.py` — считает тайминги слов диктора (для караоке-подсветки
  и для синхронизации появления иконок/заголовков с речью), пишет `word_layout.json`.
- `caption_filter.py` — генерирует filter_complex для субтитровой плашки
  (crop-маска караоке-подсветки, вызывается из `render_scenes.sh` и
  `render_icon_scenes.py`).
- `pill_gen_all.py` — генератор скруглённых pill-бейджей (PIL): подписи под
  иконками И заголовки главной мысли используют один и тот же генератор/стиль.
- `render_scenes.sh` — рендер сцен "только аватар" (плюс устаревшие функции
  для icon-сцен старого образца, оставлены для истории).
- `render_icon_scenes.py` — рендер icon-сцен (стикер-иконки + pill-подписи +
  субтитры), актуальная версия.
- `render_headlines.py` — накладывает заголовок главной мысли поверх уже
  отрендеренных сцен (шаг 4, после шагов 2-3).
- `build_concat_cmd.py` — финальная склейка с кроссфейдами + фоновая музыка.
- `fonts/Inter-Bold.otf` — единственный шрифт во всём ролике (субтитры,
  подписи, заголовки — везде один и тот же файл).
- `ambient_bed.m4a` — фоновая музыка (микшируется тихо под озвучку).
